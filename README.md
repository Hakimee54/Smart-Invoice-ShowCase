# Smart Invoice

**Smart Invoice** is a production invoice management SaaS designed to help freelancers and small businesses manage invoices, monitor payments, and automate payment follow-ups from one place.

## What It Does

Smart Invoice reduces the manual work involved in managing clients, invoices, payments, reminders, and financial records.

### Key Features

* Invoice and client management
* Partial payment tracking
* Automated overdue payment reminders
* Manual payment reminders
* PDF invoice receipts
* Client history reports
* Invoice history reports
* Date-based analytics and reporting
* Activity tracking
* Authentication and account management
* Automated email workflows
* Production deployment

## Tech Stack

* **Backend:** Python, FastAPI
* **API:** REST APIs
* **Frontend:** HTML, CSS, JavaScript
* **Database:** PostgreSQL
* **Deployment:** Production web environment
* **Automation:** Scheduled email reminder workflows
* **Documentation:** FastAPI / OpenAPI

The application uses a FastAPI backend with structured REST endpoints for authentication, invoices, clients, reports, reminders, user settings, and other application functionality.
